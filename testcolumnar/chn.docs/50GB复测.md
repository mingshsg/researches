# 50GB 最终复测（变更说明）

在独立集群 `es-testcolumnar:9201` 上，用同一套 mapping/settings 把数据量从 5GB 扩到 **50GB NDJSON**，作为最终压缩结果。

## 计划变更

1. 生成 `/mnt/docker-data/testcolumnar/logs-50gb.ndjson`（不删除已有 5GB 文件）。
2. 重建五套已通过校验的测试索引（仅删 ES 索引数据，不删项目文件），避免 5GB 与 50GB 结果混在同一索引。
3. 写入顺序：logsdb stored → logsdb_columnar columnar_stored → standard stored → standard disabled → logsdb_columnar synthetic + pattern_text。
4. 每套仍先校验 settings/mappings，再 ingest + forcemerge + `_disk_usage` + 字段查询。
5. 当前 license 为 trial，创建时必须回读确认 Basic 场景仍是 `stored` / `columnar_stored` / `disabled`，Enterprise 场景才是 `synthetic`。

磁盘：`/mnt/docker-data` 约 261GB 可用；50GB 原始文件 + 约 80GB 索引可放下。
